# 🚀 Markdown Quick Reference Card

## Text Formatting
| Syntax | Result |
|--------|--------|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `***bold italic***` | ***bold italic*** |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `` `code` `` | `code` |

## Headings
```markdown
## Main Section (H2)
### Subsection (H3)
#### Small Heading (H4)
```

## Lists

### Bulleted
```markdown
- Item 1
- Item 2
  - Sub-item
```

### Numbered
```markdown
1. First
2. Second
3. Third
```

### Task List
```markdown
- [x] Done
- [ ] Todo
```

## Links & Images
```markdown
[Link text](url)
[Link with title](url "tooltip")
![Image alt](image.jpg)
```

## Tables
```markdown
| Column 1 | Column 2 |
|----------|----------|
| Data 1   | Data 2   |
```

### Alignment
```markdown
| Left | Center | Right |
|:-----|:------:|------:|
```

## Quotes & Code

### Quote
```markdown
> Important note here
```

### Code Block
````markdown
```javascript
code here
```
````

## Horizontal Line
```markdown
---
```

## Special Characters

### Emojis (Copy-Paste)
```
✅ ❌ ⚠️ ℹ️ 📌 💡 🔬 💊 📊 📞 ⏰ 🎯
```

### Symbols
```markdown
&copy; = ©
&reg; = ®
&trade; = ™
```

## Common Patterns

### Info Box
```markdown
> ℹ️ **Bilgi:** Önemli bilgi buraya.
```

### Warning Box
```markdown
> ⚠️ **Uyarı:** Dikkat edilmesi gereken.
```

### Success Box  
```markdown
> ✅ **Başarılı:** Olumlu bilgi buraya.
```

### List with Bold Headers
```markdown
- **Başlık 1**: Açıklama metni
- **Başlık 2**: Açıklama metni
- **Başlık 3**: Açıklama metni
```

### Numbered Steps
```markdown
1. **İlk Adım**
   - Alt detay
   - Başka detay

2. **İkinci Adım**
   - Alt detay
```

## Tips 💡

✅ **DO:**
- Leave blank lines between elements
- Use `##` for main sections
- Keep tables simple
- Use lists for readability

❌ **DON'T:**
- Use `#` (reserved for page title)
- Forget blank lines
- Use inline HTML
- Make tables too wide
